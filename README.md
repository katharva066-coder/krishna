# 📰 Ultimate News Bot

AI-powered news bot with:
- Real-time sentiment analysis (FinBERT + VADER)
- Ensemble ML predictions (XGBoost + LightGBM + Random Forest)
- Voice alerts, breakout detection, technical indicators
- Live dashboard with dark mode & WebSocket

## Deploy on Render
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

## Environment Variables
- `TELEGRAM_BOT_TOKEN`: Your bot token
- `TELEGRAM_CHAT_ID`: Your Telegram chat ID

## Features
- 25+ RSS feeds
- Multi-user support
- Price triggers & breakout alerts
- Auto-archive & A/B testing
